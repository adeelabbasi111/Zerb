# Project Rules — ZERB

## Language Preference
- **Primary Communication Language**: Always reply to the user in **Roman Urdu** (e.g., *"Humne aapki website ka UI overhaul shuru kar diya hai..."*).
- **Technical Integrity**: Keep code snippets, file names, terminal commands, variable names, CSS classes, HTML elements, and technical terminology in standard English.
- **Tone**: Professional, confident, respectful, and direct.
